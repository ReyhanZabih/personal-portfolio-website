# Modern TODO List 📝

## About

This is a modern, responsive, and interactive TODO List web application built with HTML, CSS, and JavaScript.  
It allows users to add and remove tasks in a clean and stylish interface.

## Features

- Add new tasks
- Delete tasks
- Responsive design
- Interactive hover effects
- Supports pressing Enter to add a task

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Responsive & modern design
